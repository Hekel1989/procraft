The problem: two actions mixed into a list of kinds, far from Generate

A · Krita's way: a Control part in the popover, with a trace button on each row (recommended)

Left: no control layer yet. The popover always shows a small Control part with “+ Line art” and “+ Scribble”: each adds an empty control layer just above the current one, ready to draw on. Right: after tapping “+ Line art”, its row, with the trace button beside ×. Tapping it fills that layer with lines traced from what's visible (the control layers themselves left out). If you'd already drawn on it, it's replaced, and one undo brings yours back.

A · Krita's way

Both ways of making a control (drawing it or tracing it) start in one place, next to the prompt. Re-trace any time after changing the picture.
  • Tracing takes two taps
  • Adds one short row to the popover when empty

B · One-tap trace

Quickest for tracing.
  • Drawing your own is in a different place (Layers panel)
  • No re-trace: you'd delete and trace again

C · In the Layers panel

Popover untouched.
  • Still far from where you generate
  • A tiny button on a busy layer row, worse on a tablet
  • Needs a control layer to exist first
